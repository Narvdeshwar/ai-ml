# Three type of inheritance
## 1. Single level inheritance
```markdown
    Parent
      |
      |
    Child
```
## 2. Multilevel inheritance
```markdown
        Parent
          |
        Child
          |
       Subchild
```
## 3. Multiple inheritance
```
        Parent1       Parent2
          |              |
          -------|--------
                 |
               Child
```
